Phase A · 杠杆率最高
📦

复用资产盘点

这是 Agent 时代杠杆率最高的一步。

有组件目录 → Agent 直接复用 → 少写代码 → 少出 bug

没有组件目录 → Agent 每次从零写 → 代码膨胀
📤 Output: 复用映射表 + 组件目录
🎯 目标复用率 ≥ 60%
