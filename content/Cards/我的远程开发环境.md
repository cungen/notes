## 安装

OpenClaw
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
openclaw onboard
// 我使用的 Glm 模型
```

Claude 及 OpenCode，推荐使用智谱的交互式工具安装，还可以顺带帮你修改模型供应商配置
```bash
npx @z_ai/coding-helper
// 更新
npm install -g @anthropic-ai/claude-code
// 推荐安装 oh-my-claude
```

```
docker run --security-opt seccomp=unconfined --name sandbox --network host -d -p 8080:8080 ghcr.io/agent-infra/sandbox:latest
```
