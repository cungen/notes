> [!WARNING] 如果某些快捷键不生效，大多情况可能是输入法或没有选择对象的原因，可以切到英文输入法或尝试选择对象后尝试
> 
## 界面

- tab: 切换 object mode 和 edit mode 
- \`: 可以切换视角
- z: 可以切换显示模式(线框、渲染、模型等)
- n: 侧边工具栏
- Shift + 鼠标右键：可以设置参考点位置
- Shift + Space: 可以弹出左侧工具栏，再加一个菜单中的对应按键，可以快捷使用某个工具

## 选择

- Ctrl + 鼠标左键：取消框选
- Ctrl + 鼠标左键：添加框选
## 基本变形

- s: scale可加x,y,z来指定方向
- r: rotate旋转
- g: grab移动
- e: extrude挤出
- Ctrl + B: 选择边后，可以细分斜角
- x: 除了删除作用外，还可以在选择面或多个边后，来 dissolve edge 取消细分或取消环切
- m: 合并


## 其他

- Ctrl + a: apply，在模型变形之后，可以通过apply来使用scale恢复到1，这样做细节或环切的其他操作，也不会受变形影响，导致不同轴比例不一致
- Ctrl + r: 环切
- Ctrl + j：组合
	- 后续可以在编辑模式下，按p来单独选择组中元素

## 工作区

- 可以先把某一个区域切换到 Preference 类型，然后就可以，可以点击view -> area -> 水平或竖直分隔了
