## 前置条件

| 条件 | 要求 |
|------|------|
| 微信开放平台账号 | 已注册通过审核 |
| 移动应用 | 已创建并审核通过，获取 AppID |
| 小程序 | 已发布，获取**原始ID**（`gh_` 开头） |
| 关联关系 | 移动应用和小程序必须在**同一开放平台账号下绑定** |
| SDK 版本 | iOS ≥ 1.8.4，Android ≥ 6.5.4 |

## 操作步骤

### 第1步：绑定移动应用与小程序

登录 open.weixin.qq.com → 管理中心 → 移动应用 → 关联小程序信息 → 绑定

> [移动应用打开小程序 - 微信官方文档](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/Launching_a_Mini_Program/Launching_a_Mini_Program.html)

### 第2步：集成微信 Open SDK

**iOS**:
- `pod 'WechatOpenSDK'`
- Info.plist 添加 `LSApplicationQueriesSchemes`（weixin）

**Android**:
- build.gradle 添加依赖
- AndroidManifest.xml 声明权限和 activity

> [iOS 接入指南](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/Access_Guide/iOS.html)
> [Android 接入指南](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/Access_Guide/Android.html)

### 第3步：获取小程序标识

小程序管理后台 → 设置 → 基本设置 → 原始ID（gh_xxx 格式）

> [获取账号信息 - 小程序文档](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/get-account-info.html)

### 第4步：调用打开接口，通过 path 传参

**iOS (Objective-C)**:

```objc
WXLaunchMiniProgramReq *req = [[WXLaunchMiniProgramReq alloc] init];
req.userName = @"gh_xxxxxxxxxxxx";         // 小程序原始ID
req.path = @"pages/detail/index?id=12345"; // 参数拼在path里
req.miniProgramType = WXMiniProgramTypeRelease;
[WXApi sendReq:req completion:nil];
```

**iOS (Swift)**:

```swift
let req = WXLaunchMiniProgramReq()
req.userName = "gh_xxxxxxxxxxxx"
req.path = "pages/detail/index?id=\(id)"
req.miniProgramType = .release
WXApi.send(req) { success in
    print("sendReq success: \(success)")
}
```

**Android (Kotlin)**:

```kotlin
val req = WXLaunchMiniProgram.Req().apply {
    userName = "gh_xxxxxxxxxxxx"
    path = "pages/detail/index?id=12345"
    miniprogramType = WXLaunchMiniProgram.Req.MINIPTOGRAM_TYPE_RELEASE
}
api.sendReq(req)
```

**Android (Java)**:

```java
WXLaunchMiniProgram.Req req = new WXLaunchMiniProgram.Req();
req.userName = "gh_xxxxxxxxxxxx";
req.path = "pages/detail/index?id=" + itemId;
req.miniprogramType = WXLaunchMiniProgram.Req.MINIPTOGRAM_TYPE_RELEASE;
api.sendReq(req);
```

**小程序端接收**:

```javascript
Page({
    onLoad(options) {
        console.log(options.id) // "12345"
        console.log(options.source) // 任意自定义参数
    }
})
```

### 第5步：处理回调

通过 `WXLaunchMiniProgramResp`（iOS）或 `WXEntryActivity.onResp`（Android）获取打开结果。

## 参数传递方式

### 方式一：path 拼接 query（推荐）

参数直接拼到小程序页面路径中，兼容性最好：

```
pages/detail/index?id=12345&source=app&token=abc
```

### 方式二：extMsg 附加信息

```objc
req.extMsg = @"{\"orderId\":\"12345\"}";
```

> **注意**: extMsg 在 iOS 上可能为空，不要依赖它传递关键参数。

### 编码建议

含中文或特殊字符时先 `encodeURIComponent` / `stringByAddingPercentEncodingWithAllowedCharacters`。

## 注意事项

| 问题 | 说明 |
|------|------|
| 未绑定小程序 | 必须在同一开放平台账号下绑定 |
| 原始ID格式 | `userName` 必须是 `gh_` 开头，不是小程序 AppID |
| path 参数编码 | 特殊字符需编码，否则参数丢失 |
| 小程序未发布 | 正式版才能用 Release，开发/体验版用对应枚举 |
| 每日调用上限 | 每 App 每天最多打开 1000 次 |
| extMsg 平台差异 | iOS 上可能收不到，关键参数走 path |

## 错误码

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 0 | 成功 | - |
| -1 | 错误 | 检查参数和网络 |
| -2 | 用户取消 | 提示已取消 |
| -3 | 未安装微信 | 提示安装微信 |

## 最佳实践

1. 打开前检查微信是否安装：`WXApi.isWXAppInstalled()`
2. 检查微信版本：`WXApi.getWXAppSupportApi()` 确保版本支持
3. 关键参数走 path，不依赖 extMsg
4. 对参数做 URL 编码
5. 开发阶段用 `.test` / `.preview` 打开体验版/开发版
